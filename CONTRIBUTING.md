# Contributing

Contributions are welcome when they improve skill quality, portability, documentation, or validation.

Before opening a pull request:

1. Preserve the existing skill directory structure.
2. Keep a valid YAML frontmatter block at the top of every `SKILL.md`.
3. Use a unique, descriptive skill name and description.
4. Keep scripts, references, assets, and templates in relative paths.
5. Document new dependencies and usage requirements.
6. Update the relevant catalog page and `CHANGELOG.md`.

Please do not include credentials, private data, destructive commands, or unlicensed third-party material.
